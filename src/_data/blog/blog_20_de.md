Eine Geschenkkarte ist das sichere Geschenk: Die beschenkte Person wählt die Songs, macht die Karten, niemand liegt daneben. Aber wenn du ihre Musik kennst, ist das bessere Geschenk das, bei dem du die Auswahl gemacht hast. Der Sommer, in dem ihr euch kennengelernt habt, die Band, die ihr zusammen gesehen habt, die Songs aus ihrem Geburtsjahr.

Früher war der Haken, was nach dem Überreichen passiert. Das Set blieb in deinem Konto, also blieben auch das PDF, die Spiele und das App-Design bei dir. Das ist jetzt gelöst: Du verschenkst das Set mit einem Geschenkgutschein, und sobald er eingelöst ist, gehört es ihnen.

## Warum ein Set und keine Geschenkkarte

Eine Geschenkkarte übergibt ein Budget. Ein Set übergibt eine Auswahl, die du für eine bestimmte Person gemacht hast, und der Moment, der das Ganze so gut macht, ist, wenn jemand die dritte Karte umdreht und den Song erkennt.

Das passiert nur, wenn die Songs für sie ausgesucht wurden. Eine Geschenkkarte ist immer noch die richtige Antwort, wenn du keine Ahnung hast, was sie hören, und du findest sie auf der [Geschenkkarten-Seite](/[lang]/giftcard). Wenn du es weißt, mach das Set.

## So funktioniert es

1. **Bestell die Karten wie gewohnt**, in deinem eigenen Namen, zu dir nach Hause. Wähle eine Playlist oder füge deine eigene ein, [gestalte die Karten](/[lang]/blog/[post:3]), nimm eine [Geschenkbox](/[lang]/blog/[post:14]) dazu, wenn du möchtest. In der Bestellung steht nichts über das Geschenk.
2. **Erstelle den Geschenkgutschein in Mein Konto.** Wähle beim Set *Als Geschenk geben*. Gib ein, für wen es ist, von wem es kommt, eine kurze Nachricht und in welcher Sprache es gedruckt werden soll. Du kannst mehrere Sets aus derselben Bestellung auf einen Geschenkgutschein setzen.
3. **Druck ihn aus oder leg ihn dazu.** Der Geschenkgutschein ist ein A5-PDF mit ihrem Namen, deiner Nachricht, einem QR-Code und einem Code zum Eintippen. Druck ihn aus, falte ihn in die Box, steck ihn in eine Karte.
4. **Sie lösen ihn ein**, indem sie den Code scannen oder qrsong.io/redeem öffnen. Sie melden sich an oder erstellen ein kostenloses Konto mit einer E-Mail-Adresse, einem Code, den wir schicken, und einem Passwort. Das Set wandert in ihr Konto, neben alle Playlists, die sie schon haben.

Wenn die Karten gedruckt sind, funktionieren sie schon vorher: Jede Person kann eine Karte mit der kostenlosen QRSong! App scannen und abspielen. Das Einlösen gibt ihnen den Rest.

## Was mitgeht

Alles, was zum Set gehört:

- **Die Karten in deinem Design.** Sie wurden so gedruckt, also bleiben sie auch so.
- **Das PDF**, für Karten zum Selberdrucken, das sie wieder aus ihrem eigenen Konto herunterladen können.
- **[QRGames](/[lang]/blog/[post:13]), wenn du es hinzugefügt hast.** Musik Bingo, Musik Trivia und Musik Timeline für diese Playlist, gehostet aus ihrem Konto. Es ist ein Add-on für [price:games] pro Playlist; wenn sie den Link des Geschenkgutscheins öffnen, sehen sie, ob es zum Set gehört.
- **Dein App-Design, wenn du eins gemacht hast.** Mit dem [App Designer](/[lang]/app-designer) wechselt die kostenlose QRSong! App zu deinem Design, sobald die erste Karte gescannt wird. Das funktioniert auf ihren Karten weiter, nachdem das Geschenk eingelöst wurde.

Was nicht mitgeht, ist der App Designer selbst. Er ist ein Upgrade in deinem Konto und bleibt dort, zusammen mit deiner Bestellung und deiner Rechnung. Sie bekommen das Design, das du für diese Karten gemacht hast; wenn sie es ändern möchten, können sie den App Designer selbst holen.

## Es bleibt geheim

Wir kontaktieren die Person, der du es schenkst, nie. Nichts ändert sich, bis sie den Geschenkgutschein einlöst, und wenn sie das tut, sieht sie „ein Geschenk von“ deinem Namen und deine Nachricht. Sie sieht nie, was du bezahlt hast, deine Bestellnummer oder deine Rechnung.

Nach dem Einlösen bekommst du eine kurze E-Mail, dass der Geschenkgutschein eingelöst wurde, und das Set in deinem Konto wird als verschenkt angezeigt.

## Timing für Nikolaus und Weihnachten

Der Geschenkgutschein kann erstellt werden, sobald das Set bereit zum Überreichen ist:

- **Digitale Karten:** sobald das PDF bereit ist.
- **Gedruckte Karten:** sobald sie an die Druckerei gegangen sind. Bis dahin kannst du noch Korrekturen machen, und du kannst die Bestellung noch ändern.

Bestell ein gedrucktes Set also früh genug, damit die Karten ankommen, und erstelle den Geschenkgutschein, wenn Mein Konto sagt, dass es möglich ist. Auf der [Versandseite](/[lang]/shipping-info) stehen die Lieferzeiten pro Land.

## Ein paar Dinge, die helfen

- **Schreib die Nachricht.** Sie wird auf den Geschenkgutschein gedruckt, und sie ist der Teil, den Menschen aufbewahren.
- **Leg den Geschenkgutschein in die Box**, oben auf die Karten. Er erklärt jemandem, der sie noch nie gesehen hat, was die Karten sind.
- **Verloren?** Storniere den Geschenkgutschein in Mein Konto und erstelle einen neuen. Der alte Code funktioniert sofort nicht mehr.

Die komplette Anleitung findest du auf der Seite [QRSong! verschenken](/[lang]/gift).

## FAQ

### Kann ich QRSong! Karten jemand anderem schenken?

Ja. Bestell die Karten wie gewohnt und wähle dann beim Set in Mein Konto Als Geschenk geben. Du bekommst einen Geschenkgutschein zum Ausdrucken oder zum In-die-Box-Legen. Wenn sie ihn einlösen, wandert das Set mit dem Kartendesign in ihr eigenes Konto, und mit QRGames und deinem App-Design, falls du sie hinzugefügt hast.

### Brauchen sie ein QRSong! Konto?

Nur zum Einlösen des Geschenkgutscheins, und das dauert eine Minute: eine E-Mail-Adresse, ein Code, den wir schicken, und ein Passwort. Gedruckte Karten funktionieren sofort mit der kostenlosen QRSong! App, bevor irgendjemand irgendetwas einlöst. Wenn sie schon ein Konto haben, kommt das Geschenk zu ihren eigenen Playlists dazu.

### Sehen sie, was ich bezahlt habe?

Nein. Sie sehen, von wem es ist, und deine Nachricht. Der Preis, die Bestellnummer und die Rechnung bleiben in deinem Konto.

### Kann ich den App Designer verschenken?

Der App Designer bleibt in deinem Konto. Das App-Design, das du für das Set gemacht hast, geht mit und wird weiter auf ihren Karten in der QRSong! App angezeigt. Wenn sie sich den App Designer selbst holen, können sie es ändern.

### Wann kann ich den Geschenkgutschein erstellen?

Bei digitalen Karten, sobald das PDF bereit ist. Bei gedruckten Karten, sobald sie an die Druckerei gegangen sind; bis dahin sagt dir Mein Konto, dass das Set noch nicht verschenkt werden kann.

### Was, wenn der Geschenkgutschein verloren geht?

Storniere ihn in Mein Konto und erstelle einen neuen. Der alte Code funktioniert sofort nicht mehr, und das Set bleibt in deinem Konto, bis der neue Geschenkgutschein eingelöst wird.
