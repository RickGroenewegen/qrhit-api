Je vois sans arrêt la même question dans mes recherches, et elle ne vient pas de gens qui cherchent un jeu pour une soirée. Elle vient de musiciens : comment mettre un QR code sur une affiche, une carte de visite, un panneau de table de merch ou au dos d’une pochette vinyle, pour que quelqu’un puisse viser avec son téléphone et écouter ta musique.

Je fabrique des cartes QR musicales pour gagner ma vie, donc j’ai passé beaucoup trop de temps sur ces détails. Voilà ce qui marche vraiment, y compris les points qui piègent souvent les gens.

## La version de base prend deux minutes

1. Ouvre la page de ton morceau, album ou artiste sur Spotify, Apple Music, Bandcamp ou là où il se trouve, puis copie le lien de partage.
2. Colle ce lien dans n’importe quel générateur de QR code gratuit.
3. Choisis un code **statique**, pas un code dynamique.
4. Télécharge-le en SVG si tu l’intègres dans une maquette, ou en PNG à 300 dpi si ce n’est pas le cas.

Ça te donne un QR code qui fonctionne. Le reste de cet article, ce sont les détails qui font la différence entre un code que les gens scannent et un code qu’ils ignorent.

## Statique ou dynamique, et pourquoi c’est encore plus important pour les musiciens

Un code statique contient le lien directement dans le motif. Il est gratuit, il n’expire jamais, et il ne peut pas être coupé parce qu’une entreprise ferme. Un code dynamique contient une URL de redirection qui pointe vers le serveur de quelqu’un d’autre, qui renvoie ensuite vers ton lien. Ça te donne une destination modifiable et des statistiques de scan, mais ça cesse de fonctionner le jour où ce service ferme ou quand ton essai se termine.

Pour une affiche qui reste en place trois semaines, le dynamique peut très bien convenir, et les statistiques sont vraiment utiles. Pour tout ce qui est imprimé de façon durable, surtout du merch ou une pochette de disque, utilise du statique. Un QR code mort sur un objet physique que tu as vendu à quelqu’un, ça donne une mauvaise image pendant des années.

Si tu veux pouvoir modifier la destination sans dépendre d’un service externe, fais pointer un code statique vers une URL que tu contrôles, une page de ton propre site, puis change ce que fait cette page. Le code ne change jamais, la destination t’appartient.

## Fais-le pointer vers un endroit qui marche pour tout le monde

C’est l’erreur que je vois le plus. Un lien Spotify ne sert à rien pour quelqu’un qui utilise Apple Music, et un lien Bandcamp ne parle pas forcément à quelqu’un qui passe juste devant et veut écouter la chanson.

Les options, à peu près dans l’ordre de ce qui marche le mieux :

- **Ta propre page d’atterrissage.** Le mieux, si tu en as une. Tu la contrôles, elle marche pour tout le monde, et tu peux changer ce qu’elle contient sans réimprimer quoi que ce soit.
- **Un smart link.** Les outils qui font un seul lien pour tous les services règlent exactement ce problème, et leurs offres de base sont gratuites. Même réserve que pour les codes dynamiques : il y a le serveur de quelqu’un d’autre au milieu.
- **Un lien vers un seul service.** Très bien quand tu sais que ton public est là, ce qui est souvent vrai à une table de merch dans une salle. Beaucoup moins bien sur une affiche dans la rue.

Quel que soit ton choix, scanne-le toi-même, sur le téléphone de quelqu’un d’autre, avant d’en imprimer cent.

## L’imprimer pour qu’il scanne vraiment

- **Taille.** Environ 2 cm de côté, c’est le minimum pratique. 2,5 à 3 cm pardonne davantage. Sur une affiche que les gens scanneront à deux mètres, vise beaucoup plus grand : environ un dixième de la distance de lecture est une bonne règle.
- **Zone silencieuse.** Laisse un espace vide tout autour, environ quatre modules. Les designers détestent ça, et c’est la raison la plus fréquente pour laquelle un code échoue.
- **Contraste.** Code foncé sur fond clair. Clair sur fond foncé marche avec certains scanners et échoue avec d’autres, et tu ne sauras lesquels que quand quelqu’un te le dira.
- **Ne l’étire pas.** Redimensionne-le proportionnellement. Un code écrasé est un code cassé.
- **Évite le pli.** Sur une pochette ouvrante ou un flyer plié, garde-le loin de la pliure.
- **Teste l’impression réelle**, pas l’écran. L’encre qui bave sur un papier non couché referme les espaces d’une manière qu’un aperçu PDF ne montrera jamais.

## Là où un QR code mérite sa place

Les tables de merch, parce que quelqu’un qui vient de te voir jouer scannera avant même d’avoir décidé d’acheter. Les affiches et flyers, quand l’alternative est d’espérer que les gens se souviennent de ton nom. Le dos d’une carte de visite. À l’intérieur d’une pochette vinyle ou CD, pour renvoyer vers la version numérique ou vers un bonus. Les bannières de scène, si elles sont assez grandes pour être scannées depuis le public.

Là où il ne mérite pas sa place : partout où quelqu’un ne peut pas physiquement s’arrêter pour pointer son téléphone dessus, et partout où il n’y a pas de réseau mobile.

## FAQ

### Quel est le meilleur QR code pour un musicien ?

Un code statique qui pointe vers une page d’atterrissage que tu contrôles. Statique veut dire qu’il n’expire jamais et ne dépend pas de la survie d’une autre entreprise. Une page qui t’appartient veut dire que tu peux changer où elle envoie les gens sans réimprimer quoi que ce soit.

### Les générateurs de QR code sont-ils gratuits ?

Les codes statiques sont gratuits et illimités chez la plupart des générateurs, sans compte. Tu paies quand tu veux des codes dynamiques, des destinations modifiables ou le suivi des scans.

### Quelle taille doit faire un QR code sur une affiche ?

Environ un dixième de la distance à laquelle les gens vont scanner. Une affiche lue à deux mètres demande un code d’environ 20 cm. À bout de bras sur un flyer, 2 à 3 cm suffisent largement.

### Un QR code peut-il renvoyer vers Spotify et Apple Music en même temps ?

Pas directement, un code contient une seule URL. Fais-le pointer vers une page d’atterrissage ou un smart link qui propose les deux, et ça marche pour tout le monde, peu importe le service utilisé.

### Mon QR code peut-il arrêter de fonctionner ?

Un code statique, non : le lien est dans le motif. Ce qui casse, c’est la destination. Si la page bouge ou si le service ferme, le code scanne toujours mais n’arrive nulle part, c’est pour ça que le faire pointer vers un domaine que tu contrôles vaut l’effort.

### Est-ce que je dois mettre un QR code sur un vinyle ou un CD ?

Oui, et utilise un code statique pour ça. Les pochettes survivent à la plupart des services de raccourcissement de liens, et un code mort dans un disque que quelqu’un a acheté n’est pas quelque chose que tu peux réparer plus tard.
