Ik zie steeds dezelfde vraag in mijn zoeklogs, en die komt niet van mensen die een partyspel zoeken. Het zijn muzikanten: hoe zet je een QR-code op een poster, visitekaartje, bordje op je merchtafel of de achterkant van een vinylhoes, zodat iemand zijn telefoon erop kan richten en je muziek kan horen.

Ik maak voor mijn werk QR music cards, dus ik heb veel te veel tijd besteed aan de details hiervan. Dit is wat echt werkt, inclusief de dingen waar mensen vaak op vastlopen.

## De basisversie kost twee minuten

1. Open je track, album of artiestenpagina in Spotify, Apple Music, Bandcamp of waar je muziek ook staat, en kopieer de deellink.
2. Plak die link in een gratis QR-codegenerator.
3. Kies een **statische** code, geen dynamische.
4. Download hem als SVG als je hem in een ontwerp zet, of als PNG op 300 dpi als je dat niet doet.

Dat is een werkende QR-code. De rest van deze post gaat over de dingen die het verschil maken tussen een code die gescand wordt en een code die genegeerd wordt.

## Statisch of dynamisch, en waarom dat voor muzikanten extra belangrijk is

Een statische code bevat de link in het patroon zelf. Hij is gratis, verloopt nooit, en kan niet worden uitgezet doordat een bedrijf failliet gaat. Een dynamische code bevat een redirect-URL die naar iemands server wijst, en die server stuurt daarna door naar jouw link. Daarmee krijg je aanpasbare bestemmingen en scanstatistieken, maar hij stopt met werken zodra die dienst ermee stopt of je proefperiode afloopt.

Voor een poster die drie weken hangt is dynamisch prima, en de statistieken zijn echt nuttig. Voor alles wat blijvend gedrukt wordt, en zeker voor alles wat op merch of een platenhoes komt, gebruik je statisch. Een dode QR-code op een fysiek object dat je aan iemand hebt verkocht, ziet er nog jaren slecht uit.

Als je aanpasbaarheid wilt zonder die afhankelijkheid, laat een statische code dan wijzen naar een URL die jij beheert, een pagina op je eigen site, en verander wat die pagina doet. De code verandert nooit, de bestemming is van jou.

## Laat hem wijzen naar iets dat voor iedereen werkt

Dit is de fout die ik het vaakst zie. Een Spotify-link is nutteloos voor iemand op Apple Music, en een Bandcamp-link zegt weinig tegen een voorbijganger die gewoon het nummer wil horen.

Opties, ongeveer op volgorde van hoe goed ze werken:

- **Je eigen landingspagina.** Het beste, als je er een hebt. Jij beheert hem, hij werkt voor iedereen, en je kunt wijzigen wat erop staat zonder iets opnieuw te drukken.
- **Een smart link.** De verschillende tools voor één link naar alle diensten lossen precies dit op en zijn aan de onderkant gratis. Zelfde waarschuwing als bij dynamische codes: er zit een server van iemand anders tussen.
- **Een link naar één dienst.** Prima als je weet dat je publiek daar zit, wat bij een merchtafel in een zaal vaak zo is. Niet prima op een poster op straat.

Wat je ook kiest, scan hem zelf, op de telefoon van iemand anders, voordat je er honderd laat drukken.

## Zo druk je hem zodat hij echt scant

- **Formaat.** Ongeveer 2 cm in het vierkant is het praktische minimum. 2,5 tot 3 cm is vergevingsgezinder. Op een poster die mensen vanaf twee meter scannen moet je veel groter gaan: ongeveer een tiende van de kijkafstand is een prima vuistregel.
- **Witte ruimte.** Laat rondom vrije ruimte over, ongeveer vier modules breed. Ontwerpers haten dit, en het is de meest voorkomende reden dat een code faalt.
- **Contrast.** Donkere code op een lichte achtergrond. Licht op donker werkt bij sommige scanners en faalt bij andere, en je ontdekt pas welke wanneer iemand het je vertelt.
- **Rek hem niet uit.** Schaal hem proportioneel. Een platgedrukte code is een kapotte code.
- **Vermijd de vouw.** Op een gatefold of gevouwen flyer houd je hem uit de buurt van de vouwlijn.
- **Test de echte print**, niet het scherm. Inkt die uitloopt op ongestreken papier maakt de openingen kleiner op een manier die je in een PDF-preview nooit ziet.

## Waar een QR-code zijn plek verdient

Merchtafels, want iemand die je net heeft zien spelen scant voordat diegene heeft besloten om iets te kopen. Posters en flyers, waar het alternatief is hopen dat ze je naam onthouden. De achterkant van een visitekaartje. In een vinyl- of cd-hoes, met een link naar de digitale versie of iets extra's. Banners op het podium, als ze groot genoeg zijn om vanuit het publiek te scannen.

Waar hij zijn plek niet verdient: ergens waar iemand niet fysiek kan stoppen en een telefoon erop kan richten, en ergens zonder mobiel bereik.

## FAQ

### Wat is de beste QR-code voor een muzikant?

Een statische code die wijst naar een landingspagina die jij beheert. Statisch betekent dat hij nooit verloopt en niet afhankelijk is van een ander bedrijf dat in de lucht blijft. Een eigen pagina betekent dat je kunt veranderen waar je mensen naartoe stuurt zonder iets opnieuw te drukken.

### Zijn QR-codegenerators gratis?

Statische codes zijn bij de meeste generators gratis en onbeperkt, zonder account. Je betaalt wanneer je dynamische codes, aanpasbare bestemmingen of scantracking wilt.

### Hoe groot moet een QR-code op een poster zijn?

Ongeveer een tiende van de afstand waarvandaan mensen scannen. Een poster die op twee meter wordt gelezen heeft een code van ongeveer 20 cm nodig. Op armlengte op een flyer is 2 tot 3 cm genoeg.

### Kan een QR-code tegelijk naar Spotify en Apple Music linken?

Niet direct, een code bevat één URL. Laat hem wijzen naar een landingspagina of smart link die beide aanbiedt, dan werkt hij voor iedereen, ongeacht wat ze gebruiken.

### Stopt mijn QR-code ooit met werken?

Een statische code niet: de link zit in het patroon. Wat kapot kan gaan is de bestemming. Als de pagina verhuist of de dienst sluit, scant de code nog steeds maar landt hij nergens, en daarom is wijzen naar een domein dat jij beheert de moeite waard.

### Moet ik een QR-code op vinyl- of cd-verpakking zetten?

Ja, en gebruik daar een statische code voor. Verpakking leeft langer dan de meeste linkverkorters, en een dode code in een plaat die iemand heeft gekocht kun je later niet meer repareren.
